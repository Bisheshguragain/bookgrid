## 🎨 Visual Design Elements

### Color Scheme
```
Primary:    #7C3AED (Purple)
Secondary:  #4F46E5 (Indigo)
Success:    #10B981 (Green)
Text:       #1F2937 (Gray-900)
Background: #FFFFFF (White)
Accent:     Gradients from blue-50 to purple-50
```

### Typography Hierarchy
```
H1: 5xl-7xl (48-72px) - Hero headline
H2: 4xl-5xl (36-48px) - Section headers
H3: 2xl (24px) - Card titles
Body: xl (20px) - Descriptions
Small: base-sm (14-16px) - Details
```

### Spacing System
```
Section Padding:  py-20 (80px vertical)
Card Padding:     p-8 (32px all sides)
Grid Gap:         gap-8 (32px between items)
Button Padding:   px-8 py-4 (32px x 16px)
```

## 📱 Responsive Breakpoints

### Mobile (< 768px)
```
- Single column layout
- Stacked pricing cards
- Full-width CTAs
- Hamburger menu (in app)
- 4xl heading size
```

### Tablet (768px - 1024px)
```
- 2-column grids
- Medium spacing
- 5xl heading size
- Side-by-side CTAs
```

### Desktop (> 1024px)
```
- 3-column pricing grid
- Maximum spacing
- 7xl heading size
- Full-width hero
- Maximum container width: 7xl (1280px)
```

## 🔄 User Flow

### First-Time Visitor Journey
```
1. Land on hero
   ↓
2. Read compelling headline
   ↓
3. See "Free forever" message → Trust built
   ↓
4. Scroll through features → Understand value
   ↓
5. Read "Why Upgrade?" → Context for tiers
   ↓
6. Review pricing → Compare options
   ↓
7. Click "Start Free Today" → Begin signup
```

### Returning Visitor Journey
```
1. Navigate to landing page
   ↓
2. Click "View Pricing" in hero
   ↓
3. Scroll directly to pricing section
   ↓
4. Review updated plans
   ↓
5. Click appropriate CTA
```

## 💡 Design Principles

### Trust & Transparency
- "Free forever" messaging
- "No credit card required"
- Clear feature limits
- Honest pricing
- "Cancel anytime" copy

### Visual Hierarchy
- Pro plan is most prominent
- Clear price differentiation
- Bold key features
- Graduated complexity (Free → Pro → Business)

### Conversion Optimization
- Multiple CTAs throughout page
- Social proof via testimonials
- Clear value proposition
- Reduced friction (no CC for free)
- Direct upgrade path

### Accessibility
- High contrast ratios
- Clear heading structure
- Keyboard navigation
- Screen reader friendly
- Touch-friendly tap targets (48px minimum)

