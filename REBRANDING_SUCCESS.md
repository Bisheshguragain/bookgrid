## 🌐 Domain Setup (Next Steps)

### 1. Register Domain
Register **bookgrid.com** with your preferred registrar:
- Namecheap
- GoDaddy
- Google Domains
- Cloudflare

### 2. Configure DNS
Point domain to your hosting:
```
A Record: @ → [Your server IP]
CNAME: www → bookgrid.com
```

### 3. SSL Certificate
Enable HTTPS:
- Most hosting providers (Vercel, Netlify) provide free SSL
- Or use Let's Encrypt

### 4. Update Environment
In production environment:
```env
VITE_APP_URL=https://bookgrid.com
```
