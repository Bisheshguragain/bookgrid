## 🎯 Brand Guidelines

### Logo Usage

**Do:**
✅ Use on white or light backgrounds
✅ Maintain clear space around logo
✅ Use official purple color (#9333ea)
✅ Keep proportions intact

**Don't:**
❌ Stretch or distort logo
❌ Change colors arbitrarily
❌ Add effects or shadows
❌ Place on busy backgrounds

### Typography

**Primary Font:** Helvetica / System Sans-Serif
- **Headings:** Bold (700)
- **Body:** Regular (400)
- **UI Elements:** Medium (500)

**Hierarchy:**
```
H1: 30px / Bold   → Page titles
H2: 24px / Bold   → Section headers
H3: 18px / Semi   → Subsections
Body: 16px / Reg  → Main content
Small: 14px / Reg → Helper text
Tiny: 12px / Reg  → Metadata
```

## 🎨 Design System

### Components
```
Buttons:
  Primary   → Purple gradient (#9333ea to #7e22ce)
  Secondary → White with purple border
  Tertiary  → Text only, purple color

Cards:
  Background → White
  Border     → Light gray (#e5e7eb)
  Hover      → Purple border
  
Inputs:
  Border     → Gray (#e5e7eb)
  Focus      → Purple ring
  Error      → Red border

Badges:
  Info       → Purple background
  Success    → Green background
  Warning    → Yellow background
  Error      → Red background
```

### Spacing Scale
```
xs:  4px   (0.25rem)
sm:  8px   (0.5rem)
md:  16px  (1rem)
lg:  24px  (1.5rem)
xl:  32px  (2rem)
2xl: 48px  (3rem)
```

### Border Radius
```
sm:  4px   → Small elements
md:  8px   → Inputs, buttons
lg:  12px  → Cards
xl:  16px  → Containers
full: 999px → Pills, avatars
```
